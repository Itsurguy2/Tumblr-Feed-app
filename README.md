// The Tumblr Feed App is a lightweight iOS application that lets users browse photo posts 
// from a public Tumblr blog. It pulls in content from the Tumblr API and presents it in 
// a clean, scrollable feed. Each post includes:
//
//    • A photo (if available)
//    • A short summary or caption
//    • The date it was posted
//    • A list of hashtags (from Tumblr, or generated using AI keywords)
//
// 🔄 Key Features:
// - Pull-to-refresh functionality to update the feed with new posts
// - Automatic image loading with graceful fallbacks if unavailable
// - Clean and responsive UI using `UITableView` and custom table view cells
// - Dynamic tag generation from captions when no tags are available
//
// 🧪 Designed for:
// - Practicing RESTful API integration in Swift
// - Exploring JSON decoding using `Codable`
// - Applying basic AI/logic for data enhancement
// - UI building using Interface Builder or XIB files
//
// 🔧 Possible Future Features:
// - Dynamic blog selection (choose any Tumblr blog)
// - Detail view on post tap (larger photo, full caption)
// - Image caching for smoother scrolling
// - On-device machine learning for better tag generation
